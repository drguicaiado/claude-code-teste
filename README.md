# claude-code-teste

Repositório de teste para explorar o fluxo de trabalho com o Claude Code.

## Sobre

Este projeto contém exemplos simples para praticar:

- Criação de branches e pull requests
- Revisão de código assistida por IA
- Boas práticas de commits

## Como usar

```bash
# Instalar dependências
pip install -r requirements.txt

# Executar o exemplo
python calculadora.py
```
